# WB.Logging.Base

The base library for WB.Logging.

## 📦 Package

Nuget: [WB.Logging.Base](https://www.nuget.org/packages/WB.Logging.Base/)

## Features

- `ILogger` interface: Defines the core logging functionality that all loggers must implement.
- `ILogSink` interface: Defines the contract for log sinks, which are responsible for processing log messages.
- `LogMessage` class: Represents a log message, including its level, content, and timestamp.
- `LogLevel` enum: Defines the various levels of log severity (e.g., Info, Warning, Error).
